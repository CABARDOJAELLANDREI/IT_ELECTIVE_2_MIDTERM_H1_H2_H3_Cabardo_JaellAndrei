# 📚 Multiverse Comics & Collectibles

## 🏪 Store Overview & Theme
* **Store Name**: Multiverse Comics & Collectibles
* **Theme**: Modern Dark-Slate & Neon Accent E-Commerce
* **Description**: A customized online storefront designed for comic book enthusiasts and collector vault items. It features dynamic inventory status badges, interactive order tables, card animations, and a seamless checkout flow.

---

## 🚀 Instructions on How to Run the Application

### Prerequisites
* [.NET 8.0 SDK](https://dotnet.microsoft.com/download) (or latest)
* Visual Studio 2022 (with **ASP.NET and web development** workload)

### Steps to Run via Visual Studio

1. **Open the Solution**
   Double-click the `.sln` file to open the project in Visual Studio.

2. **Restore Dependencies**
   Right-click the Solution in **Solution Explorer** and select **Restore NuGet Packages**.

3. **Run the Project**
   * Press **`F5`** (or click the green **Play** button with the project name at the top bar).
   * Visual Studio will automatically launch your browser to the storefront homepage (typically at `https://localhost:7xxx`).
